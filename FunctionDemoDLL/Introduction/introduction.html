CANape FunctionDLL Demo

Overview

This Demo includes some examples of using own functions from a dll file in CANape. More information about the creation of such a dll file and how to integrate this into CANape will be explained in the following application note:
AN-IMC-1-012_How_to_use_C-Code_Functions_in_CANape.pdf

Page "Flip a string"

The source code of the demodll can be found here. An example of a function in this demo is the function "RotateString". In the panel you can enter a string in the input field. This string will be rotated and displayed into the output field by a click on the RotateStringTxt button. Input and output string are saved in global variables (gInputString and gOutputString) of the CANape Functions Editor. The buttons "RotateString" and "ClearWindow" are connected respectively to the scripts "RotateString.cns" and "ClearGlobalStringValues.cns". One will call the RotateString function and the other will clear the input and output fields as well as both global variables.
Go to page "Flip a string"

Page "MinMaxValue"

Another examples of functions in the demodll are the functions ArithMinV and ArithMaxV. These two functions calculate respectively the minimum and the maximum of an input signal if the measurement is started by clicking the start button on the panel at this page. In this Demo the minimum and the maximum value of channel1 will be saved into the global variables gArithMaxV and gArithMinV of the CANape Functions Editor. If the measurement is started, by clicking the start button of the StartStop Panel, the global variables will be set to zero. The function ArithMinMax, in CANape's Functions Editor, will call the functions ArithMinV and ArithMaxV of the demodll.dll file every time channel1 is measured. The function ArithMinMax has also to be configured in the Measurement list of CANape and should have as measurement mode "on channel1". This means that the function will be called each time the channel1 is changed. The amplitude of the signal channel1 could be changed with the CalibrateAmpl Panel.
Go to page "MinMaxValue"

Page "MinMaxArray"

At this page the global variable (array) gArithMaxArray can be analysed by some functions of the demodll.dll. Three buttons on the panel allow to calculate the maximum, the minimum and the average value of the gArithMaxArray. The calculated values can be shown in the write window of CANape displayed at the top of this page. The values of the global array gArithMaxArray can be changed in the Panel window or in the Parameter-Explorer in CANape.
Go to page "MinMaxArray"

Page "CopyArray"

Example of function ChangeBuffer1D of the demodll.dll file. This function will copy all values from the global array gArithMaxArray to the global array gBuffer1. The values of gArithMaxArray can be changed in the panel window of gArithMaxArray. The Copy Array button, in the panel window, will call the script "ChangeBuffer1D.cns", which will copy all the values from gArithMaxArray to gBuffer1. The Clear Target button, in the panel window, will call the script "ClearGlobalBuffer1D.cns", which will set all values of the global array gBuffer1 to zero. The scripts are also defined in CANape's Functions Editor.
Go to page "CopyArray"
